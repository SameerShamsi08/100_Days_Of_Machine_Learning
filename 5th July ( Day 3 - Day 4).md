**Day 3** - Learned about the Types of Machine Learning 

-Supervised Learning
-Unsupervised Learning
-Semi-Supervised Learning
-Reinforcement Learning

*In Supervised Learning the algorithm learns from the labelled data where we have input and output both.
*In Unsupervised Learning the algorithm learn from the unlabelled data where we have only input values.
*Semi-Supervised Learning is used when the data is both supervised and unsupervised
*Reinfocement Learning is best for images and videos datas

**Day 4** - Batch Learning vs Online Learning 

Batch learning can also be called as offline learning where we train the data and deploy the model that was trained using that data after that whenever we want to make some changes we have
bring the model back from live section and then again train the data and deploy it again.

On the other hand , Online learning can train the model while it's live by feeding the new data on it that is required, it is highly efficient but it's very complex to learn.
